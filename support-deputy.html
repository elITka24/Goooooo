👤 Назначение сотрудника

  1. Добавить участника в чат Тех.Поддержки.
  2. Предоставить все форумы и провести проверку с записью.
  3. Выдать права или повысить ранг через бота.
  4. Выдать права группы: «Удаление сообщений» и «Права на войс».

В правах группы установить префикс:

Тех.поддержка

⬆️ Повышение

Для повышения сотрудника используется команда:

Повысить

⬇️ Понижение

Для понижения сотрудника используется команда:

Понизить

🚫 Снятие сотрудника

Для снятия сотрудника используется команда:

Разжаловать

После этого необходимо убрать права группы.

⚙️ Права группы

Для сотрудников Тех.Поддержки должны быть выданы необходимые права:

  • Удаление сообщений
  • Права на войс
